## AI өнцгийн нэмэлт шинжилгээ (AI debrief)
Аппын спецификацийг AI туслахад өгч exploratory тестийн charter санал болгоход, AI нь үндсэн GUI болон API согогуудаас гадна хүрээний утгын шинжилгээ (Boundary Value Analysis) болон Injection аюулгүй байдлын нэмэлт сценариудыг санал болгосон нь миний сонгосон Supermodel болон Saboteur аялалуудыг илүү өргөжүүлэх боломжтойг харуулсан. Харин өөрийн түүхий тэмдэглэлийг өгч bug report үүсгүүлэхэд алдааны тайлангийн стандарт бүтцийг хурдан гаргасан боловч "Red validation error message" гэх мэт бодит спецификацид байхгүй улаан өнгөтэй тодорхой текстаар алдаа заана гэж зохиож нэмсэн (hallucinate хийсэн). Энэхүү туршилтын нотолгоо болон харилцан яриаг `ai-experiments/` хавтаснаас харах боломжтой бөгөөд AI-ийн гаргасан тайланг инженер заавал бодит апп дээр дахин шалгах шаардлагатайг харууллаа.
