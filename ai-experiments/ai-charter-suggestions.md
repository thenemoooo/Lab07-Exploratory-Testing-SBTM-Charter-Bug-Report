# AI-аас санал болгосон Charter-уудын туршилт

## AI-д өгсөн prompt:
"Уншлагын жагсаалт вэб аппын спецификаци:
- Ном нэмэхэд Гарчиг, Зохиолч, Он заавал бөглөгдөнө.
- Он нь 1000-2100 хооронд бүхэл тоо байна.
- Ижил гарчиг, зохиолчтой ном давхардахгүй.
- Хайлт том/жижиг үсэг ялгахгүй.
- POST хүсэлтэд буруу JSON ирвэл 400 алдаа буцаана.
Энэ аппад exploratory тестийн charter-ууд санал болго."

## AI-ийн хариулсан санал:
1. Boundary Value Analysis Tour (Он талбарт 999, 1000, 2100, 2101 болон сөрөг тоо оруулах)
2. Security & Injection Tour (Title болон Author талбарт `<script>` эсвэл SQL injection болон хэт урт текст оруулах)
3. Stress & Persistence Tour (Маш олон ном нэмж, серверийг Ctrl+C-ээр дахин асаахад санах ойн төлөв хэрхэх)

## Харьцуулалт ба Дүгнэлт:
Миний бичсэн `charter.md` нь Supermodel (GUI) болон Saboteur (API) аялалд төвлөрсөн байсан бол AI нь хязгаарын утгын шалгалт (Boundary analysis) болон аюулгүй байдлын (Injection) чартаруудыг нэмж санал болгосон.
