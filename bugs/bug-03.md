# BUG-03: Буруу JSON биетэй POST хүсэлтэд 400 алдааны код буцаахгүй байна

Орчин:  Уншлагын жагсаалт v2.0, curl, macOS, 2026-10-16
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан
Дахин баталгаажсан: 2026-10-23 session-д (нотолгоо: evidence/2026-10-23/bug03-invalid-json.txt)

## Дахин гаргах алхам
1. Терминал дээр дараах командуг ажиллуулах:
   curl -i -X POST localhost:3000/api/books -d 'invalid json'
2. Серверийн HTTP статусын кодыг шалгах.

Хүлээгдэж байсан: Буруу JSON биетэй POST хүсэлтэд 400 Bad Request алдаа буцаах ёстой.
Бодит үр дүн:     Сервер HTTP/1.1 200 OK буцааж байна.

Ноцтой байдал: Critical — API алдаа боловсруулалт буруу ажиллаж байна.
