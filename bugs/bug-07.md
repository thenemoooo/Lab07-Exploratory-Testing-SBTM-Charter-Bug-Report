# BUG-07: Аюултай «Устгах» товч улаан биш, ногоон өнгөтэй байна

Орчин:  Уншлагын жагсаалт v2.0, Chrome, macOS, 2026-10-23
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. http://localhost:3000 руу орох.
2. Хүснэгтийн мөр бүрийн баруун талд байрлах «Устгах» товчнуудын өнгийг харах.

Хүлээгдэж байсан: Спецификаар аюултай үйлдлийн товч (Устгах) улаан өнгөтэй байх ёстой.
Бодит үр дүн:     «Устгах» товч бүгд ногоон өнгөтэй харагдана (computed style: #2C7A4B).

Ноцтой байдал: Minor — Спецификаас зөрсөн зураглал (өнгө), үйлдэл өөрөө эвдрээгүй тул Minor.
